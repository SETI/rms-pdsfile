# plans/

This directory holds planning documents for the rms-pdsfile modernization
effort: the top-level modernization plan and any focused analyses or sub-plans
it references. The current documents are the modernization plan
(`2026-07-17-modernization-plan.md`), which is the complete, self-contained
specification the effort executes, and the unified mini-holdings analysis
(`2026-07-21-unified-mini-holdings-analysis.md`), which studies whether the
manufactured test-data tree can be shared with rms-opus. Files are dated in
their names; when a plan is superseded, the latest version is kept and older
drafts are removed. Deviations from an active plan are recorded as dated
addendum files here and acknowledged by the owner before the deviating change
merges.
